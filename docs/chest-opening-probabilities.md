# 开箱系统概率设计

皇室战争式开箱的完整概率设计。代码实现见 `src/chest_opening.py`,相关数据模型见 `src/models.py`(ChestItem / Inventory.letters)。总览与分布图见 [probability-design.md](probability-design.md)；文档索引见 [README.md](README.md)。

> 设计原则:**右偏** —— 多数时候中规中矩,偶尔大惊喜。所有分布都朝「低值常见、高值罕见」倾斜,避免均匀分布带来的「平淡」。

---

## 1. 解锁时长(确定性,非随机)

按宝箱稀有度固定解锁倒计时,真实时间走时(关掉应用照常):

| 稀有度 | 时长 |
|--------|------|
| 普通 | 30 分钟 |
| 罕见 | 1 小时 |
| 稀有 | 2 小时 |
| 史诗 | 4 小时 |
| 传奇 | 8 小时 |

- 最多 **4 个**宝箱同时解锁(`MAX_UNLOCK_SLOTS`),超出需等空槽
- 倒计时存盘,重启应用续走(`ChestItem.unlock_started_at` 时间戳)

### 加速 / 秒开(确定性,非随机)

未就绪箱可用金币立刻解锁或秒开(跳过动画)。费用只看**剩余解锁秒数**,与稀有度掉落无关:

```
cost = ceil(remaining_seconds / SPEEDUP_SECONDS_PER_GOLD)    # 每 300 秒(5 分钟) 1 金,至少 1
```

- 普通满时(30 分)约 **6 金**;传奇满时(8 小时)约 **96 金**
- 同稀有度可一次秒开多只(先校验总费用再逐只开)
- 已就绪箱可批量开箱并跳过逐箱动画,结果走短汇总面板(`ui_chest_summary.py`)

## 2. 字母数量:几何分布(右偏,0-∞)

**概率质量函数:**

```
P(X = k) = (1 − p)^(k−1) · p      k = 1, 2, 3, …     p = 0.5
```

**分布表:**

| 数量 | 概率 |
|------|------|
| 1 个 | 50.0% |
| 2 个 | 25.0% |
| 3 个 | 12.5% |
| 4 个 | 6.25% |
| 5 个 | 3.1% |
| … | 逐级减半 |
| 7 个以上 | ≈ 0.8% |
| 20 个(截断) | ≈ 1e-6(可忽略) |

- **均值** = 1/p = **2 个**
- 实现截断在 `LETTER_COUNT_MAX = 20`(21+ 概率约百万分之一,可忽略)
- 单箱内字母不重复(从 26 字母池不放回抽取)

## 3. 字母稀有度:加权分布

每个字母独立按权重抽稀有度,权重由**宝箱稀有度**决定:

```
P(稀有度 = i) = w_i / Σw
```

| 宝箱 \\ 字母 | 普通 | 罕见 | 稀有 | 史诗 | 传奇 |
|--------------|------|------|------|------|------|
| **普通箱** | 70% | 20% | 7% | 2% | 1% |
| **罕见箱** | 50% | 28% | 15% | 5% | 2% |
| **稀有箱** | 30% | 30% | 25% | 12% | 3% |
| **史诗箱** | 15% | 25% | 30% | 22% | 8% |
| **传奇箱** | 5% | 12% | 28% | 30% | 25% |

宝箱越稀有,分布整体右移:传奇箱开出传奇字母的概率是普通箱的 **25 倍**。

![字母稀有度权重分布](img/letter_rarity_weights.svg)

## 4. 伴生货币:对数正态(右偏,0-∞)

### 命中概率(每箱独立判断)

| 货币 | 命中概率 |
|------|----------|
| 金币 | 50% |
| 钻石 | 20% |

金币与钻石**互相独立**(一箱可能都掉、掉一个或都不掉)。

### 命中后的金额:对数正态分布

```
X ~ LogNormal(μ, σ²)      μ = ln(mean) − σ²/2      σ = 0.6

E[X] = mean               (期望恰为设定均值)
```

按稀有度的条件均值:

| 宝箱 | 金币均值 | 钻石均值 |
|------|----------|----------|
| 普通 | 2 | 0.2 |
| 罕见 | 4 | 0.4 |
| 稀有 | 7 | 0.9 |
| 史诗 | 12 | 2 |
| 传奇 | 18 | 4 |

### 分布特征(σ = 0.6)

| 特征 | 取值 | 含义 |
|------|------|------|
| 众数 | ≈ 0.58 × mean | 最常开出的金额,明显低于均值 |
| 中位数 | ≈ 0.84 × mean | 一半的箱子低于此值 |
| 均值 | = mean | 长期期望 |
| P(X > 10·mean) | ≈ 0.0018% | 彩蛋尾值(约 1/55000 出 10× 均值) |
| 上限 | 无(0-∞) | 理论上可爆出极大值 |

**这就是"保底靠刷、大头靠脸"**:绝大多数开箱在均值附近偏下,偶尔一发入魂。

## 5. 数值示例

### 普通箱(典型)

- 字母:2 个(最常见),多为普通/罕见,如 `C·普通` + `M·罕见`
- 金币:50% 概率掉 ~1.5(多数 1.0-1.8)
- 钻石:20% 概率掉 ~0.15

### 传奇箱(典型)

- 字母:2-3 个,常见史诗/传奇,如 `A·史诗` + `X·传奇`
- 金币:50% 概率掉 ~13(多数 10-16)
- 钻石:20% 概率掉 ~3

### 传奇箱(彩蛋,约 1/55000)

- 字母 5+ 个 + 金币 180+(10× 均值)+ 钻石 40+(需 3 项同时爆,实际更罕见)

## 6. 调参指南

所有参数集中在 `src/chest_opening.py` 常量:

| 常量 | 作用 | 调整方向 |
|------|------|----------|
| `UNLOCK_SPANS` | 各稀有度解锁秒数 | 调大=等待更久更稀缺 |
| `MAX_UNLOCK_SLOTS` | 同时解锁槽位数 | 调大=更宽松 |
| `SPEEDUP_SECONDS_PER_GOLD` | 加速/秒开:每多少剩余秒折 1 金 | 调大=加速更便宜 |
| `GEOMETRIC_P` | 字母数量几何分布 p | 调大=数量更少(均值 1/p 减小) |
| `LETTER_COUNT_MAX` | 数量截断 | 一般不用动 |
| `LETTER_RARITY_WEIGHTS` | 5×5 稀有度权重 | 改权重即可偏转分布 |
| `GOLD_HIT_P` / `DIAMOND_HIT_P` | 货币命中概率 | 调高=货币更常见 |
| `GOLD_MEAN` / `DIAMOND_MEAN` | 各稀有度货币均值 | 调大=货币更肥 |
| `CURRENCY_SIGMA` | 对数正态形状 σ | 调大=尾部更肥(更常爆大值) |

改完参数后运行 `python docs/gen_probability_charts.py` 重新生成分布图。
